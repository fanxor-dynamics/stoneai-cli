# Issue Resolution Record

## Symptoms
Describe the observed behavior, exact error/status, affected user or system, detector, and reproducible signal.

## Root cause
State the proven cause. If not proven, write `unproven` and name the next probe in Future outlook.

## Fix
List the exact remediation: file, PR, commit, deploy, config, schema, runbook, customer-approved action, or no-code decision.

## Results
Paste external verification evidence: test output, curl/browser probe, CI run, deployed SHA equality, query result, screenshot, customer confirmation, or monitoring result.

## Preventative measures
Name recurrence controls. Repeatable issue classes need at least one enforcement-layer control: CI, Cedar, runtime probe, synthetic monitor, lint, schema guard, or invariant test.

## Future outlook
State residual risk, monitoring window, recurrence risk, owner, follow-up trigger, and what would reopen the issue.
